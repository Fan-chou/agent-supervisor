# UI 设计：「值班台」

> **风格修订（Jack 反馈 v1 花哨）**：视觉改为 Linear 式克制风格，以文末「§9 Linear 式风格」为准；§4 配色、§6 组件里与之冲突的（渐变、阴影、大面积彩色、环图）作废。信息架构（§2）、三态形状约定（§3）不变。

桌面前端（`ui/`，MyGo 原生 GPU 绘制）的全新设计。不沿用旧界面的任何布局或视觉。

## 1. 设计理念

**一句话**：一台安静的仪表台，平时只让你瞥一眼，出事时一眼看清「发生了什么、有没有真的被拦住」。

1. **先结论，后细节**。第一屏（总览）回答三个问题：现在是观察还是拦截？今天有几次危险操作？有没有真的被拦？
2. **三态靠形状，不靠颜色**。这是整个产品最重要的视觉约定（见 §3），灰度截图里仍可区分。
3. **每次命中独立成条**，不合并、不折叠成计数；计数只出现在汇总处，且旁边永远能点进逐条列表。
4. **只读**。唯一的写入口是「规则」页的启用开关和阈值输入，页头与输入旁都明示。
5. **安静的底色，克制的强调**。暖纸色（浅）/ 石墨色（深）的中性底；只有三态与告警使用高饱和色。

## 2. 信息架构

左侧窄导航轨（72px，图标+文字，Cmd+1…6）；顶部页头右侧常驻「三态计数」与连接/模式/Judge 状态。

| 页 | 内容 |
|---|---|
| 总览 | 模式说明、今日三态大数字、进行中的会话、最近危险事件（逐条）、规则命中分布、Judge/系统健康 |
| 会话 | 左：按项目分组的会话卡片；右：该会话的「心跳条」+ 时间线（调用为主轴，命中逐条挂在下方）+ 右侧命中检视器 |
| 危险 | 全部危险事件账本（逐条），三态筛选，按类别/会话的分布 |
| 规则 | 规则列表（命中柱、开关）+ 详情（统计、结局构成、阈值编辑）。X2 显示锁，不可停用 |
| Judge | 页签：裁决记录（汇总条 + 列表 + 详情）/ 路由（路由链卡片 + 健康） |
| 回放 | 运行列表（可选 A/B 对比）、对比表、评测报告 |

## 3. 三态（核心约定）

| 状态 | 含义 | 形状 / 材质 | 图标 | 文案 | 灰度下 |
|---|---|---|---|---|---|
| 危险 | 检测到危险操作（属性，与是否拦截无关） | 浅暖色底的圆角标签 + 实线细边 | 三角警示 | `危险·类别` | 三角形 + 浅底 |
| 会拦（观察） | 本应拦截，但当前为 shadow/advise，**未生效** | **空心、虚线描边、斜体、无填充** | 空心盾 | `会拦 · 未生效`（ask 则 `会问 · 未生效`） | 虚线空框 |
| 已拦截 | enforce 下**真正**拦下/要求确认 | **实心墨色块、反白粗体** | 盾+勾 | `已拦截` / `已要求确认` | 黑色实心块 |

- 「会拦」和「已拦截」永不同形：一个是幽灵（透过去能看见背景），一个是最重的实心块。时间线节点同理：空心虚线圆 vs 实心方块。
- 大数字磁贴同样用这三种材质，所以总览一眼就能分辨「本应拦 3 / 已拦 0」。
- 模式文案固定：shadow →「观察模式：不会拦截任何操作」；enforce →「拦截已开启」。

## 4. 配色

浅色「暖纸」/ 深色「石墨」。语义色在两套主题下各一版。

| 角色 | 浅 | 深 |
|---|---|---|
| 背景 | `#F4F2EC` | `#0E1013` |
| 卡片 | `#FFFFFF` | `#171A1F` |
| 卡片悬停/次级底 | `#F0EDE5` | `#1E2228` |
| 边线 | `#E3DFD3` | `#2A2F37` |
| 文字 / 次要 | `#1D1B16` / `#6F6A5D` | `#E8E6E1` / `#8E9099` |
| 强调（选中、焦点） | `#4F46E5` 靛蓝 | `#8B93FF` |
| 危险 | `#D93A1E` 朱红 | `#FF6A4D` |

等级 H/M/L 用「▲ ● ·」+ 颜色双编码。

## 5. 字体

系统字体（中文由系统回退，PingFang/微软雅黑等）；命令/路径/id 用 `monospace`。数字用 `tnum` 等宽数字。

| 层级 | 字号/字重 |
|---|---|
| 大数字（三态磁贴） | 40 / 700 |
| 页标题 | 20 / 650 |
| 区块标题 | 13 / 600 |
| 正文 | 13 / 400 |
| 辅助、标签 | 12 / 400，次要色 |
| 等宽 | 12 |

## 6. 组件

- **卡片**：圆角 14，1px 边线；浅色加极淡阴影，深色加 1px 内描边高光。
- **导航轨**：选中项有一块会滑动的靛蓝软底（`Animate`），图标 Lucide 风格线性图标。
- **三态标签 / 磁贴 / 时间线节点**：见 §3，集中在 `ui/app/kit.go`。
- **心跳条**：会话页顶部，一格一次调用，有命中的格子变高并按三态着色/造型；点击跳到对应调用。
- **检视器**：会话页/危险页右侧可收起的面板（命中链路：决策、阈值、观测值、judge）。
- **图表**：`ui/chart`——规则命中堆叠柱（L/M/H）、危险类别环形图、Judge 延迟条。
- **动效**：页面切换淡入上移 200ms；导航软底滑动；活跃会话呼吸点；数字计数过渡；悬停卡片抬升。尊重系统「减弱动态效果」。
- **图标**：`ui/app/icons.go`（内联 SVG），Lucide 线性图标（ISC / 部分 MIT，许可全文见 `ui/app/icons/LICENSE`）。

## 7. 页面布局（1440×900 基准，最小 960×600）

- **总览**：顶部「模式横幅」（渐变底，一句话结论）；其下三个大磁贴（危险 / 会拦 / 已拦）并排；再下方两列——左「进行中的会话」卡片网格，右「最近危险事件」逐条；最底一行：规则命中柱图、危险类别环、Judge 与系统健康。
- **会话**：Split，左 340 会话列表（项目分组、可折叠、搜索、状态过滤），右为时间线。时间线顶部是会话头（id、harness、模型、目录、三态小计）和心跳条，主体为竖向轨道；命中卡片缩进挂在调用下，选中后右侧滑出检视器。
- **危险**：顶部三态分段筛选 + 汇总；主体为逐条事件卡片（时间、会话、类别、被拦对象、原因、三态标签）；右侧分布图。
- **规则**：左 380 规则列表；右详情：头部（ID、标题、等级、开关）、统计格、结局构成条、阈值编辑区（保存/恢复默认）。
- **Judge**：页签；裁决记录为左列表右详情；路由为纵向「路由链」卡片，每张带健康条、p95、解析失败率、最近失败。
- **回放**：左运行列表（勾选两个做 A/B），右对比表（增减用 ▲▼ + 颜色）与运行详情/评测报告。

## 8. 状态与异常

- 连接状态机沿用（实时 / 重连 / 降级轮询 / 离线）；离线时内容区半透明并出横幅，保留旧数据。
- 任何请求失败都 fail-open：显示错误行，不阻塞其他区域。
- 空状态都有一句话解释（例如「今天还没有危险操作」）。

## 9. Linear 式风格（当前生效）

- **灰阶为主**：中性灰底；文字层级只靠灰度（主文字 / 次要）。强调色只有一个（靛蓝），只用于开关、主按钮、焦点，不用于选中底色。
- **1px 细线代替阴影和色块**：无阴影、无渐变、无毛玻璃；容器是 1px 描边 + 小圆角（8），选中行只用浅灰底。
- **留白充足，字号克制**：页标题 18/600，正文 13，辅助 12，等宽 12；大数字 28。
- **颜色只给三态和告警**：危险=朱红三角（无底色）；会拦=赭金**虚线空心**斜体；已拦截=**实心墨块**反白。其余状态（成功/失败/级别）用灰度文字 + 符号（▲ ● ·），不用彩色胶囊。
- **图表**：删除环形图；规则命中柱仅灰阶（L 浅 / M 中 / H 深）；类别分布用灰色横条 + 数字。
- **图标**：16px 细线，默认灰色。
- 三态灰度可分：三角形+文字 / 虚线空框 / 实心黑块（`ln-*-gray.png` 验证）。

## 10. 交互（简约不简单）
灰阶细线风格不变，交互只增加「看不见的顺手」，不增加装饰。

**键盘**（各页一致，命令面板打开时页面不响应）
- `⌘K` 命令面板：搜页面 / 会话 / 规则，`↑↓` 选、`Enter` 跳转、`Esc` 关；输入防抖 90ms；打开时才补载规则与会话列表。只读，没有任何写操作入口。
- `J` / `↓` 下一条，`K` / `↑` 上一条，`Enter` 打开详情，`Esc` 关闭详情。危险页、会话页（左侧会话列表）、Judge 页、规则页都有。会话页另有 `Shift+J/K` 在时间线的命中之间移动，`Enter` 打开该命中的检视。
- 在输入框里打字不触发导航（输入框先吃键）。`⌘1–6` 切页、`⌘R` 刷新沿用。

**详情面板**：危险页、会话页（命中检视）、Judge 页的详情从右侧滑出，浮在列表之上（不推挤列表，列表不重排），宽 400，细线描边；`Esc` 或右上 × 关闭；面板打开时 `J/K` 带着面板切换。规则页的详情常驻在右侧（要编辑阈值，不适合临时浮层）。

**新事件**：新到的危险事件 / 命中 / 裁决行从顶部 10px 滑入（200ms，缓出），底色短暂高亮后在 1.6s 内线性淡出。首屏加载的不算新；只有再次刷新时多出来的才高亮。减弱动态效果时只做固定强度的底色高亮、无位移、到点一次性撤掉。

**提示与菜单**：导航项悬停显示「页面 · ⌘N」，页头「搜索 ⌘K」悬停显示快捷键，关闭按钮悬停显示「关闭 · Esc」。右键菜单（危险事件、命中、会话、规则、裁决）只放只读动作：查看详情、复制命令/对象/ID/路径、跳到该会话。规则的启停与阈值仍只在规则页详情里改，菜单里没有。

**动效约束**：时长 120–250ms，缓出；只动位移、透明度、底色；不在动画里重排或重建整棵树。空闲时不请求任何帧——没有常驻呼吸/脉冲动画（进行中的会话与「实时」状态用静态圆点/细环表示）；只有新事件高亮存在的那 1.6s 才逐帧请求，过期即停。
**性能**：时间线（上千行）用 `ui.List` 虚拟化；行/统计/心跳格按「数据版本 + 筛选」缓存，没变就零开销；危险页筛选结果同样缓存；新事件刷新沿用连接层 10Hz 合并，不逐条重绘。
